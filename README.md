# 🤖 Asistente de IA que Aprende - 4 Opciones

Bienvenido al proyecto de **Asistente de IA Personal** que mejora cada día.

Este proyecto tiene **4 niveles** desde lo más simple hasta lo más avanzado.

## 📚 Las 4 Opciones

### ✅ Opción 1: Asistente Básico (RECOMENDADO PARA EMPEZAR)
- Chat simple que recuerda tus preguntas
- Funciona en terminal (línea de comandos)
- Usa modelos de IA gratis (local)
- **Archivo principal:** `opcion-1-basico/assistant.py`

### ✅ Opción 2: Con Aprendizaje Personalizado
- Recuerda tus preferencias
- Mejora según lo que te gusta
- Interfaz web (puedes verlo en navegador)
- **Archivo principal:** `opcion-2-aprendizaje/app.py`

### ✅ Opción 3: Sistema Avanzado
- Base de datos completa
- Analiza cómo mejora el asistente
- Reportes detallados
- **Archivo principal:** `opcion-3-avanzado/main.py`

### ✅ Opción 4: Listo para Producción
- Desplegado en la nube (Heroku/Railway)
- Accesible desde cualquier lugar
- Con API profesional
- **Archivo principal:** `opcion-4-produccion/deploy.py`

## 🚀 Cómo Usar Este Proyecto

### Requisitos (Lo que necesitas instalar)
- Python 3.9 o superior
- pip (gestor de paquetes)
- Git (ya lo tienes si usas GitHub)

### Pasos para Empezar

1. **Clona el repositorio:**
```bash
git clone https://github.com/dorameortegaf3-cpu/ai-assistant-local.git
cd ai-assistant-local
```

2. **Instala las dependencias:**
```bash
pip install -r requirements.txt
```

3. **Ejecuta la Opción 1 (más simple):**
```bash
python opcion-1-basico/assistant.py
```
